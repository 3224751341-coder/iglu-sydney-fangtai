二、核心功能（当前能力）

功能说明
房态一览每栋楼一个表格：房型 / 面积 / 床型 / 12-24月 / 44周 / 22周 / 短租价格 / 库存 / 起租日期，按「有房先后」排序

自动登录 + 申请预填油猴脚本：登录页自动填 A1336；申请表单自动填 Agency 信息（首次手填后自动记忆）
变化通知房态有变化时自动推送企微群

三、技术架构（数据流）

  • 抓取：GitHub Actions（.github/workflows/update.yml）每小时 cron + push 触发，云端跑 update_fangtai.py（并发 12 抓取全部房型页）
  • 解析：长租日期（日期按钮 data-id）＋ 灵活起租（available-picker-start-date 起跳禁用日）＋ 短租（mnthSS 选项 + picker-start-date）＋ 合同结束日（availNowBtn data-22w/44w/6m）
  • 生成部署：生成 index.html（模板 template.html）→ wrangler 部署 Pages → 快照 data_snapshot.json 提交回仓库
  • 防假数据：404 页面检测、无信息显示「未知」而非「有房」、过期日期过滤、禁用日（buffer-days）跳过

六、维护约定（重要）

  • 改页面/脚本走 git：本地改 → git pull --rebase → push → 等 CI（约 2 分钟）→ curl 线上验证。⚠️ 不要本地直接跑全量部署（本机网络连 iglu 不稳定，会抓取不全覆盖好数据）
  • 数据自动刷新：CI 每小时 cron；线上顶部显示「更新于 …」时间
  • 排障命令：npx wrangler whoami（认证）、curl https://iglu-centralpark.pages.dev/ | grep 更新于（数据时间）
  • Agent 申请：表单看到 Agency Code: A1336 = agent 单；空白 = 先登录（脚本自动）
