Iglu Agent 自动登录 · 30 秒安装

装好后，登录 Iglu Agent Portal 再也不用手动输 A1336

🖱️ 第一步：把按钮拖到浏览器书签栏

1
确保浏览器顶部能看到书签栏（Chrome/Edge：按 ⌘+Shift+B 或 Ctrl+Shift+B 显示）
2
用鼠标按住下方按钮，拖到书签栏后松开，松手时选「完成」或「保存」：

👇 按住这个按钮，拖到上面/左侧的书签栏

🔑 Iglu自动登录
⚠️ 如果拖不动：在书签栏空白处右键 → 「添加网页…」，名称填 Iglu自动登录，网址粘贴下框里的代码，保存即可：

javascript:(function(){var i=document.getElementById('agent_code');var f=document.getElementById('agent_from');if(i&&f){i.value='A1336';i.dispatchEvent(new Event('input',{bubbles:true}));setTimeout(function(){var b=f.querySelector('input[type=submit],button[type=submit]');b?b.click():f.submit();},300);}else{alert('Open the Iglu Agent login page first');}})();

✅ 第二步：以后怎么用（2 步，零输入）

1️⃣ 在门户/房态页点右上角 「🔑 Agent Portal」 → 浏览器新标签打开 Iglu，未登录会自动停在登录页
2️⃣ 点一下书签栏里的 「🔑 Iglu自动登录」 → 自动填 A1336 并提交 → 直接进入 Portal
💡 判断是否生效：登录后打开申请表单，能看到 Agency Code: A1336，提交的申请就是 Agent 单

🔄 进阶：想要完全免点击？（可选）

  1. 浏览器安装 Tampermonkey 扩展（Edge/Chrome 扩展商店搜「Tampermonkey」）
  2. 点扩展图标 → 「添加新脚本…」→ 清空默认内容，粘贴项目目录里的 iglu-agent-autologin.user.js 全部内容
  3. 按 ⌘+S 保存。之后打开登录页就自动登录，连书签都不用点

两个方案可共存；书签方案零安装，任何浏览器（含手机外接键盘场景）都能用。
