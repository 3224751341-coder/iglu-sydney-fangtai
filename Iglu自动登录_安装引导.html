Iglu Agent 自动化 · 安装引导

一个脚本搞定：自动登录 + 申请表单自动填 Agency 信息

⚡ 装好后你会得到

🔑 登录页自动登录打开 Iglu 登录页，自动填 A1336 并提交，直接进 Portal
📝 申请表单自动预填打开申请页，自动填好 Agency 姓名/邮箱/电话
🧠 自动记忆首次申请手动填一次 Agency 信息，脚本自动记住；以后每次自动填。你手动改过也会记住新值

🌐 Chrome 用户先装 Tampermonkey（国内网络版教程）

Chrome 应用商店国内打不开，安装包已随本页面打包好，就在同一个文件夹（压缩包）里：
Tampermonkey_Chrome安装包.crx（另有 Tampermonkey解压版/ 文件夹备用）

1
Chrome 地址栏输入 chrome://extensions 回车，打开扩展管理页
2
打开右上角 「开发者模式」开关
3
把 Tampermonkey_Chrome安装包.crx 直接拖到扩展页面中间，弹窗点「添加扩展程序」
⚠️ 如果拖入时报「只支持从 Chrome 应用店添加」：改用解压加载——把 Tampermonkey解压版 文件夹整个拖到扩展页面中间（或点「加载已解压的扩展程序」选择该文件夹）。之后 Chrome 每次启动可能提示「停用以开发者模式运行的扩展程序」，点「取消」即可，不影响使用。

🛠️ 安装脚本（约 1 分钟，只需一次）

  1. 浏览器打开扩展商店，安装 Tampermonkey（油猴）：
    Chrome/Edge 地址栏直接输入 chrome.google.com/webstore（或 edge 扩展商店）搜 Tampermonkey，点「添加到浏览器」
  2. 点击浏览器工具栏的 Tampermonkey 图标 → 「添加新脚本…」（或「管理面板 → 新建脚本」）
  3. 把编辑区默认内容全部删掉，粘贴同一个文件夹（压缩包）里 iglu-agent-autologin.user.js 的全部内容
  4. 按 ⌘+S（Mac）或 Ctrl+S（Windows）保存，关闭标签页，完成 ✅
⚠️ 三个文件放一起别删：本页面（教程）+ Tampermonkey_Chrome安装包.crx（扩展）+ iglu-agent-autologin.user.js（脚本）。工作台后续有功能升级时，重新下载新的 iglu-agent-autologin.user.js 替换粘贴即可，其余不用动。

✅ 日常使用流程（已自动化部分零操作）

1️⃣ 工作台找到房型 → 点 「申请 ↗」 → 新标签打开该楼申请页（未登录会自动跳登录页并自动登录）
2️⃣ 申请表单里 Agency 信息已自动填好，Agency Code 自动显示 A1336 —— 只需填学生信息、选日期/合同、提交
💡 判断是否 agent 单：表单顶部看到 Agency Code: A1336 即为 Agent 申请。首次使用填一次 Agency 信息即可，之后全自动
