Iglu Agent 自动化 · 安装引导

一个脚本搞定：自动登录 + 申请表单自动填 Agency 信息

⚡ 装好后你会得到

🔑 登录页自动登录打开 Iglu 登录页，自动填 A1336 并提交，直接进 Portal
📝 申请表单自动预填打开申请页，自动填好 Agency 姓名/邮箱/电话
🧠 自动记忆首次申请手动填一次 Agency 信息，脚本自动记住；以后每次自动填。你手动改过也会记住新值

🛠️ 安装步骤（约 2 分钟，只需一次）

  1. 浏览器打开扩展商店，安装 Tampermonkey（油猴）：
    Chrome/Edge 地址栏直接输入 chrome.google.com/webstore（或 edge 扩展商店）搜 Tampermonkey，点「添加到浏览器」
  2. 点击浏览器工具栏的 Tampermonkey 图标 → 「添加新脚本…」（或「管理面板 → 新建脚本」）
  3. 把编辑区默认内容全部删掉，粘贴项目目录里 iglu-agent-autologin.user.js 的全部内容
  4. 按 ⌘+S（Mac）或 Ctrl+S（Windows）保存，关闭标签页，完成 ✅
⚠️ 脚本文件路径：悉尼公寓资源统一入口/iglu-sydney-fangtai/iglu-agent-autologin.user.js
如果工作台页面有更新，脚本升级后重新粘贴一次即可（平时无需动）。

✅ 日常使用流程（已自动化部分零操作）

1️⃣ 工作台找到房型 → 点 「申请 ↗」 → 新标签打开该楼申请页（未登录会自动跳登录页并自动登录）
2️⃣ 申请表单里 Agency 信息已自动填好，Agency Code 自动显示 A1336 —— 只需填学生信息、选日期/合同、提交
💡 判断是否 agent 单：表单顶部看到 Agency Code: A1336 即为 Agent 申请。首次使用填一次 Agency 信息即可，之后全自动
